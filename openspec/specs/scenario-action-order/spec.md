# scenario-action-order Specification

## Purpose
Позволить пользователю управлять порядком действий сценария и сохранять эту
последовательность при чтении, редактировании и повторном открытии сценария.

## Requirements

### Requirement: Перемещение соседних действий

Редактор SHALL позволять перемещать редактируемое действие на одну позицию
вверх или вниз. Перемещение SHALL переносить все данные действия и его задержку.

#### Scenario: Перенос действия с задержкой

- **GIVEN** редактируемый список A, B, C, где у B задана задержка 15 секунд
- **WHEN** пользователь перемещает B вверх
- **THEN** список становится B, A, C, а данные B и задержка 15 секунд сохранены

#### Scenario: Границы списка

- **WHEN** первое или последнее действие отображается в редактируемом списке
- **THEN** перемещение за соответствующую границу недоступно
- **AND** список из одного действия не допускает перемещения

### Requirement: Сохранение последовательности

Система SHALL сохранять последовательность wire-задач поддерживаемого списка
при чтении и повторной записи независимо от типов и совпадения данных задач.

#### Scenario: Разные типы

- **GIVEN** сценарий с командой устройству, TTS и ещё одной командой устройству
- **WHEN** пользователь открывает и сохраняет сценарий
- **THEN** действия остаются в исходной последовательности с теми же задержками

#### Scenario: Повторяющиеся задачи

- **GIVEN** две одинаковые команды разделены действием другого типа
- **WHEN** сценарий прочитан и записан повторно
- **THEN** обе команды сохраняются на своих позициях

#### Scenario: Сохранение выбранного порядка

- **GIVEN** пользователь изменил A, B, C на C, A, B
- **WHEN** он сохраняет сценарий и открывает его заново
- **THEN** редактор показывает C, A, B с прежними данными каждого действия

### Requirement: Выбор действия после перестановки

Редактор SHALL сохранять выбранное в визарде действие после перемещения
и изменять только локальный черновик до сохранения сценария.

#### Scenario: Пересечение выбранного действия

- **GIVEN** выбрано действие B в списке A, B, C
- **WHEN** C перемещено вверх через B
- **THEN** визард продолжает редактировать B
- **AND** исходный сценарий не изменён до сохранения

### Requirement: Сохранность неизвестных блоков

Система SHALL сохранять данные и позицию неизвестной задачи при round-trip.
Кнопки перемещения SHALL соблюдать действующие ограничения read-only сценария.

#### Scenario: Неизвестная задача между известными

- **GIVEN** сценарий с последовательностью известная A, неизвестная X, известная B
- **WHEN** сценарий прочитан и сохранён без изменения действий
- **THEN** последовательность остаётся A, X, B, а payload X сохраняется

#### Scenario: Read-only действия

- **WHEN** пользователь открывает сценарий с read-only действиями
- **THEN** перемещение этих действий недоступно, а допустимое редактирование имени и фраз сохраняется
