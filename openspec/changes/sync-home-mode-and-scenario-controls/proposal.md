# Proposal

## Why

[№62](https://github.com/dzerik/ha-sberhome/issues/62): переключатели «дома» и
автосрабатывания сценариев уже есть, но WS домашней переменной только логируется,
а stop/cancel не представлены HA-кнопками. Нужно обновление сущностей после
сигнала облака и отдельное управление исполнением сценариев.

## What Changes

- Подписка на домашние переменные и coalesced перечитка авторитетных состояний
  через существующий API без догадок о внутреннем variable payload/home_id.
- Кнопки stop/cancel на сценарий с переводами пяти языков и обработкой ошибок HA.
- Динамическое добавление кнопок новых сценариев без перезапуска; удалённые
  становятся недоступны, unique_id прежних кнопок/переключателей сохраняются.
- Публикация prerelease и отчёта в связанном issue после CI и проверки HA.

## Capabilities

### New Capabilities

- scenario-controls: WS-синхронизация домашнего режима и HA-кнопки stop/cancel.

### Modified Capabilities

Нет.

## Impact

Coordinator и button adapters, переводы, тесты, документация и версия.
Существующие группы и редактор TIME остаются как реализованы ранее.
Не переключаем присутствие реального дома и не останавливаем пользовательские
сценарии ради проверки. Облачные команды проверяются только на созданных тестовых ID.
