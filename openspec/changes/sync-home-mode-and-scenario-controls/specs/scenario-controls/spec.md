## ADDED Requirements

### Requirement: Обновление домашнего режима по WS

Интеграция SHALL перечитывать авторитетное состояние домов по WS-сигналу
домашней переменной и уведомлять HA-сущности, сохраняя плановый polling.

#### Scenario: Изменение снаружи HA
- **WHEN** приходит домашняя переменная
- **THEN** переключатели отражают состояние API каждого дома
- **AND** не применяют догадку о доме из неизвестного payload

#### Scenario: Burst и ошибка
- **WHEN** несколько сигналов приходят во время перечитки
- **THEN** выполняется повторная итерация без конкурентных GET
- **AND** ошибка не прекращает последующий polling или обработку следующих сигналов

### Requirement: Отдельные кнопки исполнения

HA SHALL предоставлять отдельные кнопки запуска, остановки и отмены сценария
со стабильными unique_id и переводами пяти языков.

#### Scenario: Нажатие control-кнопки
- **WHEN** нажата остановка или отмена
- **THEN** вызывается соответствующий метод только выбранного scenario_id
- **AND** ошибка отображается стандартной переведённой ошибкой HA

### Requirement: Жизненный цикл сценариев

Интеграция SHALL добавлять кнопки обнаруженного сценария один раз, сохранять
прежние идентификаторы и делать кнопки удалённого сценария недоступными.

#### Scenario: Новый сценарий после setup
- **WHEN** coordinator обнаруживает новый сценарий
- **THEN** его кнопки появляются без перезапуска
- **AND** повторное обновление не создаёт дубликаты
