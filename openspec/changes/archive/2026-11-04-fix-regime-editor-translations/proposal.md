# Proposal

## Why

Скриншоты docs/img_3.png и docs/img_4.png показывают ключи intents.regime_*
вместо подписей. На HA актуальные файлы, словарь содержит переводы, но версия
редактора не передаётся его зависимости i18n/index.js и словарю dicts.js.
В открытой странице ESM может повторно использовать уже вычисленные старые модули.

## What Changes

- Передавать query v редактора модулю i18n, затем самому словарю.
- Сохранить работу импортов без query для существующих потребителей.
- Добавить регрессию обновления с предварительно загруженными старыми переводами.
- Проверить рендер в браузере с устаревшим словарём и развернуть исправление на HA.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- scenario-regime-commands: переводы редактора соответствуют версии компонента.

## Impact

Два JS-модуля, frontend regression, версия 6.4.0b4. Облачные сценарии и
их содержимое при проверке не изменяются.
