# Proposal

## Why

[#67](https://github.com/dzerik/ha-sberhome/issues/67): пользователь не может
изменить порядок действий сценария. Дополнительно локально подтверждено,
что decode→encode переставляет действия разных типов даже без редактирования:
`DEVICE_COMMAND, PRONOUNCE_COMMAND` → `PRONOUNCE_COMMAND, DEVICE_COMMAND`.
Кнопки перемещения требуют исправить этот путь сохранения.

## What Changes

- Добавить кнопки «Вверх»/«Вниз» у редактируемых действий.
- Сохранять порядок действий при чтении, сохранении и повторном открытии.
- Переносить действие целиком: данные и задержка остаются с ним.
- Сохранять выбранное действие в визарде после перестановки.
- Сохранить действующие ограничения read-only для Sber-managed сценариев.

Вне объёма: drag-and-drop, новый редактор задержек, поддержка типов из №68,
изменение семантики нескольких steps облачного сценария.

## Capabilities

### New Capabilities

- `scenario-action-order`: явное управление и сохранение порядка действий.

### Modified Capabilities

Нет: каталог основных спецификаций ещё не заполнен.

## Impact

Панель `sberhome-intent-modal.js`, локализация панели, декодирование intents,
регрессионные тесты фронтенда и encoder. При реализации — документация
пользовательского поведения и согласованный MINOR-релиз по правилам репозитория.
